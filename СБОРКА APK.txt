ЗОЛОТОЙ РЕЙД — сборка APK
==========================

ГОТОВЫЙ APK УЖЕ СОБРАН
----------------------
Файл: goldraid-1.0.0-arm64-v8a_armeabi-v7a-debug.apk (~47 МБ)
Он лежит в двух местах:
  - apk\  (в корне проекта)
  - Сборка\Золотой рейд\apk\  (в комплекте для игрока)

Сборка выполнена в облаке GitHub Actions (репозиторий vova100324gg0/goldraid,
workflow «Сборка APK»). Ниже описано, как собрать APK самому, если понадобится
пересборка.

В проекте уже всё подготовлено: buildozer.spec, иконка icon.png,
заставка presplash.png, скрипты build_apk.sh / build_apk.ps1
и workflow для GitHub Actions. Быстрый запуск проверки — «СОБРАТЬ APK.cmd».

Важно: Buildozer собирает APK только на Linux. На этой Windows-машине
Linux-окружения нет, поэтому локально собрать APK прямо сейчас нельзя.
Ниже — три рабочих способа. Первый самый простой.


СПОСОБ 1. GitHub Actions (без установки Linux)
----------------------------------------------
Нужен бесплатный аккаунт GitHub и интернет.

1. Создайте на github.com новый пустой репозиторий (можно приватный).
2. Загрузите туда папку проекта. Проще всего через сайт GitHub:
   «Add file» -> «Upload files», но папку .venv и «Сборка» загружать
   не нужно — они исключены в .gitignore.
   Через git в PowerShell:
       git init
       git add .
       git commit -m "Золотой рейд 1.0.0"
       git branch -M main
       git remote add origin https://github.com/ВАШ_ЛОГИН/goldraid.git
       git push -u origin main
3. Откройте репозиторий -> вкладка Actions -> «Сборка APK» ->
   кнопка «Run workflow» -> Run.
4. Дождитесь зелёной галочки (~20-40 минут, первый раз дольше).
5. Откройте завершённый запуск, внизу раздел Artifacts ->
   скачайте goldraid-apk.zip. Внутри —
   goldraid-1.0.0-arm64-v8a_armeabi-v7a-debug.apk.

Готовый APK также выложен в разделе Releases (тег v1.0.0).


СПОСОБ 2. WSL2 на этом ПК
-------------------------
Нужны права администратора и перезагрузка. Место: ~10-15 ГБ (лучше на F:).

1. PowerShell от имени администратора:
       wsl --install -d Ubuntu
2. Перезагрузите компьютер, откройте Ubuntu, создайте пользователя.
3. В обычном PowerShell в папке проекта:
       powershell -ExecutionPolicy Bypass -File build_apk.ps1
   Скрипт сам поставит buildozer и зависимости, соберёт APK
   и положит его в папку apk.

Первая сборка скачивает Android SDK/NDK — это долго и требует интернета.
Если Ubuntu стоит на диске C:, а там мало места, перенесите проект на F:
(например, F:\goldraid) и запускайте скрипт оттуда.


СПОСОБ 3. Другая Linux-машина или сервер
----------------------------------------
Скопируйте папку проекта (без .venv) на Linux и выполните:
       bash build_apk.sh
Готовый файл появится в bin/ и будет скопирован в apk/.


УСТАНОВКА APK НА ТЕЛЕФОН ИЛИ ТВ
-------------------------------
- Телефон: скопируйте APK, откройте файл, разрешите установку
  из неизвестных источников.
- Телевизор Philips (192.168.1.100): подключите ADB и выполните
       tv-adb.cmd install apk\goldraid-1.0.0-arm64-v8a_armeabi-v7a-debug.apk
  Или: adb connect 192.168.1.100:5555
       adb install -r apk\goldraid-1.0.0-arm64-v8a_armeabi-v7a-debug.apk

APK собран в режиме debug — для установки на свои устройства этого
достаточно. Для Google Play нужен release-ключ и сборка
`buildozer android release`.


ЧТО ВНУТРИ APK
--------------
- package.domain = org.goldraid, package.name = goldraid
- version = 1.0.0, минимальный Android 5.0 (API 21), target API 33
- архитектуры arm64-v8a и armeabi-v7a
- Kivy 2.3.1 + Pillow, полноэкранный режим
- прогресс сохраняется в приватной папке приложения
