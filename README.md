# Золотой рейд

Мини-стратегия на Python + Kivy: защищай ворота, строй шахты, башни,
казармы и тотемы, собирай золото по карте, отбивай волны врагов и открывай
новые карты одну за другой.

Автор — **elsty** · текущая версия — **1.2.0**.

## Возможности
- Шесть карт-уровней, которые открываются последовательно:
  - **Зелёная долина** — 12 волн, 3 дороги к воротам, 16 площадок;
  - **Каменный перевал** — 15 волн, теснина и три дороги, 18 площадок;
  - **Пепельная пустошь** — 18 волн, четыре дороги и орды, 20 площадок;
  - **Дремучий лес** — 20 волн, четыре тропы сквозь чащу, 19 площадок;
  - **Студёная теснина** — 22 волны, три скользкие дороги, 20 площадок;
  - **Пылающий кратер** — 26 волн, пять дорог и бесконечные орды, 22 площадки.
- У каждой карты своё расположение базы, дорог, площадок и золота.
- Враги идут строго по дорогам из порталов на краю карты.
- Разные противники: гоблин, бегун, громила, щитоносец, лучник, шаман
  (лечит союзников), бомбист (взрывается), вожак и большой алый босс.
- Вожака ведёт каждый чётный отряд, а на последней волне карты выходит
  большой алый босс. Обычные враги становятся мощнее с каждой волной,
  а с 5-й волны появляются редкие элитные враги.
- Постройки: шахты приносят золото, башни стреляют, казармы готовят
  бойцов, тотем усиливает башни и бойцов рядом.
- Улучшение каждой постройки до 3 уровня и общие улучшения: орудие,
  броня героя, отряд и прочность стен базы.
- Магазин: лечение героя, ремонт базы, боевой клич и наём бойца.
- Свободное перемещение героя по всей карте, камера идёт следом.
- Золотые кучи на карте: подбери их, чтобы получить дополнительное золото.
- Звёзды за победу (1 за победу, +1 за базу выше половины здоровья,
  +1 за почти целую базу) и сохранение прогресса между запусками.
- Герой сам атакует врагов рядом, после гибели возрождается через 4 секунды.
- Поражение при разрушении базы, победа после отбития всех волн карты.

## Запуск на ПК
Дважды щёлкните `ЗАПУСТИТЬ ИГРУ.cmd` в папке проекта. Скрипт сам создаст
`.venv` и установит зависимости, если их ещё нет.

Если нужно увидеть ошибки — запустите `ЗАПУСТИТЬ С КОНСОЛЬЮ.cmd`.

Или вручную:
```bash
cd путь\к\папке\проекта
.venv\Scripts\python.exe main.py
```

Готовая папка для запуска лежит в `Сборка\Золотой рейд` — внутри есть
`ЗАПУСТИТЬ ИГРУ.cmd` и короткая инструкция.

## Прогресс
Открытые карты, звёзды и лучшая волна сохраняются в
`%APPDATA%\GoldRaid\progress.json`. Чтобы начать заново, удалите этот файл.

## Управление
### ПК
- `WASD` / стрелки — движение героя, мышь — камера и интерфейс.
- `Esc` — пауза или закрытие открытой панели.
- `1` `2` `3` `4` — выбрать постройку (шахта / башня / казармы / тотем).
- `U` — общие улучшения, `M` — магазин.
- `T` — переключить скорость боя 1x / 2x.
- `F` — досрочно вызвать следующую волну (даёт бонусное золото).
- `Пробел` — пауза.

### Телефон и ТВ
- Палец по полю — виртуальный джойстик.
- Главное меню: выбери карту и нажми, чтобы играть.
- Нижняя панель: выбери постройку, затем коснись свободной площадки.
- Кнопка `МАГ.` в верхней панели открывает магазин.
- Кнопка `УЛУЧШ.` открывает общие улучшения, не останавливая бой.
- Кнопка скорости `x1` / `x2` — темп боя.
- Тап по зданию открывает карточку: улучшение и продажа.
- Кнопка `II` — пауза: продолжить, заново, в меню.

## Android и APK
Buildozer собирает APK только на Linux. В проекте уже есть `buildozer.spec`,
иконка `icon.png`, скрипты `build_apk.sh` (Linux/WSL) и `build_apk.ps1`
(Windows-обёртка) и готовый workflow GitHub Actions.

Быстрые способы получить APK:
1. **GitHub Actions** — загрузить проект в репозиторий GitHub, открыть
   Actions → «Сборка APK» → Run workflow, скачать артефакт `goldraid-apk`.
2. **WSL2** — установить Ubuntu (`wsl --install -d Ubuntu`), затем запустить
   `powershell -ExecutionPolicy Bypass -File build_apk.ps1`.
3. **Linux-машина** — `bash build_apk.sh`.

Готовый файл: `goldraid-1.2.0-arm64-v8a_armeabi-v7a-debug.apk`.
Собранный APK лежит в `apk/` и в `Сборка/Золотой рейд/apk/`, а также
на странице загрузки:
https://vova100324gg0.github.io/goldraid-downloads/
Подробная пошаговая инструкция — в `СБОРКА APK.txt`.

Параметры APK: `org.goldraid.goldraid`, версия 1.2.0, Android 5.0+ (API 21),
target API 33, архитектуры arm64-v8a и armeabi-v7a, Kivy 2.3.1.
На Android игра открывается на весь экран, прогресс хранится в приватной
папке приложения.

## Windows
Готовая сборка — `goldraid-1.2.0-windows.zip` на странице загрузки. Распакуйте
архив в любую папку и запустите `GoldRaid.exe`. Устанавливать Python не нужно:
всё уже внутри.

Сборка из исходников:
```powershell
powershell -ExecutionPolicy Bypass -File build_windows.ps1
```
Скрипт сам создаст `.venv`, поставит зависимости и PyInstaller, соберёт папку
`build\windows\dist\GoldRaid` и архив `build\windows\goldraid-1.2.0-windows.zip`.

## Структура
- `main.py` — точка входа.
- `game/levels.py` — шесть карт: база, дороги, площадки, золото, сложность.
- `game/progress.py` — сохранение открытых карт, звёзд и рекордов.
- `game/config.py` — баланс, постройки, магазин, улучшения и виды врагов.
- `game/arena.py` — игровой цикл, экономика, строительство, волны, камера.
- `game/entities.py` — сущности: герой, враги, постройки, бойцы, эффекты.
- `game/background.py` — фон карты: дороги, палитра, деревья и скалы.
- `game/gfx.py` — примитивы рисования (круги, звёзды, многоугольники).
- `game/sprites.py` — отрисовка примитивами Kivy.
- `game/renderer.py` — сборка кадра арены.
- `game/widgets.py` — HUD, панель строительства, кнопки, всплывающие сообщения.
- `game/screens.py` — меню карт, игровой экран, пауза, улучшения, магазин, финал.
- `buildozer.spec`, `icon.png`, `presplash.png` — настройки, иконка и заставка Android.
- `build_apk.sh`, `build_apk.ps1`, `СОБРАТЬ APK.cmd`, `СБОРКА APK.txt` — сборка APK.
- `build_windows.ps1` — сборка Windows-версии (PyInstaller).
- `windows/pyi_rth_fix_site.py` — runtime-хук для Windows-сборки.
- `.github/workflows/build-apk.yml` — облачная сборка APK и Windows на GitHub.
- `LICENSE` — проприетарная лицензия (все права у elsty).
- `Сборка/Золотой рейд` — готовая папка для запуска.
